Phones only allow camera access on a trusted HTTPS page. Install the SecCam CA certificate once on each device.

Download /ca.crt

  1. Download the certificate with Chrome.
  2. Open Settings, Security and privacy, More security settings, Encryption and credentials, Install a certificate, CA certificate.
  3. Confirm the warning and pick the downloaded seccam-ca.crt.
  4. Open in Chrome.

Menu names vary by vendor; search Settings for "CA certificate".

  1. Open this page in Safari and download the certificate. Tap Allow.
  2. Open Settings, General, VPN & Device Management, tap the SecCam profile and install it.
  3. Open Settings, General, About, Certificate Trust Settings and enable full trust for the SecCam CA.
  4. Open in Safari.
  1. Debian/Ubuntu: copy the file to /usr/local/share/ca-certificates/seccam-ca.crt and run sudo update-ca-certificates.
  2. Fedora/Arch: use sudo trust anchor seccam-ca.crt.
  3. Firefox keeps its own store: Settings, Privacy & Security, View Certificates, Authorities, Import.
  4. Open .

Hosts reachable from the internet should use a real certificate (for example Let's Encrypt) through a reverse proxy instead of this local CA. See the deploy examples in the README.
